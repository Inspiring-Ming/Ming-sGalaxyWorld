About

I'm an AI Engineer and Data Scientist. I build LLM applications, AI agents and machine learning models, and the data pipelines and APIs that feed them. Most of my work has been in financial services and ESG, where the numbers have to be right and every answer has to show where it came from.

For the past four years I worked on an industry programme with Cognitivo and Westpac, through UNSW. Everything is containerised, tested in CI and evaluated with repeat runs. I led a team of four from a vague brief to a working prototype.

Before that I spent two years at a bank as a relationship manager, assessing lending and credit risk. I hold a PhD in Computer Science and Engineering from UNSW, a Master of Finance, and CFA Institute certificates in ESG investing and climate risk. I also teach machine learning, NLP and algorithms part-time at UNSW and the University of Sydney.

Featured · Agentic AI · Oct 2026

ESG Portfolio Agent

An LLM agent that answers portfolio carbon-intensity questions and runs pre-trade ESG compliance checks on top of an existing enterprise system. The model chooses each step; deterministic services do the work. The model never computes a number and never executes an action itself.

  • Role-based access: a portfolio manager and a compliance officer get different entitlements; signed session tokens and rate limits at the boundary.
  • A trade that breaches the mandate is held for approval by a second person with the override entitlement (four-eyes rule).
  • Every number in an answer must appear in a tool result or the request; otherwise the draft is rejected. Bound of 12 model calls per request.
  • Three MCP servers behind a FastAPI service, five Docker Compose services, full trace of every call.
  • Tested by: boundary-invariant probes that try to break each rule and record whether it held; every goal run three times to measure stability.

Featured · RAG & Agents · AMP AI Expo, May 2026

Reporting Agent for ESG

A question-answering service over an ESG knowledge store of 937,000 records, with two paths built to be compared: a fixed retrieval pipeline and a tool-calling agent. The simpler path stayed the default because it is cheaper and easier to test.

  • Five read-only tools over one data store; eight-turn cap instead of an open loop; tool failures returned to the model so it recovers.
  • Answers labelled as grounded in the store or extended by the model, so a reader can see what is evidenced.
  • Prompt caching with token reporting; six SASB industries, including insurance and banking.
  • Flask service, Docker, deployed on Render; shown at the AMP AI Expo.
  • Tested by: 18 pytest tests in GitHub Actions against scripted model responses, so the control flow is verified with no API key or dataset.

Featured · Data Science & Analytics

ESG Landscape Explorer

An interactive ESG analytics application that transforms 6.6M raw observations into an analysis-ready dataset covering 57,771 companies and 95 ESG metrics. Applies PCA, K-Means clustering, industry profiling, and SQL-based exploration to uncover patterns across companies and industries.

  • Found that the leading factor (17.5% of variance) measured how much each company reports, not how it performs, and flagged it as a data artefact before building on it.
  • Built K-Means company archetypes in PCA space and analysed reported vs. estimated ESG disclosures.
  • Developed an interactive dashboard with visual analytics and a read-only SQL console over curated SQLite tables.
  • Deployed as a live application on Hugging Face Spaces.

  • Implemented use cases for the Semiconductors (TC-SC) and Commercial Banking (FN-CB) industries.
  • Tested by: seven competency questions the graph must answer, a data contract on the three external datasets, and a pytest suite.

Featured · LLMs & Knowledge Graphs · Under Review

OntoMetric

An ontology-guided LLM framework that transforms ESG and sustainability standards into structured knowledge graphs through a three-stage segmentation, extraction, and validation pipeline.

  • Designed ontology-guided LLM extraction across five entity types and five relationship types.
  • Implemented semantic type verification and rule-based schema validation with provenance tracking.
  • Evaluated across SASB, TCFD, IFRS S2, and AASB S2 documents, achieving 65–90% semantic accuracy and 80%+ schema compliance.
  • Validated 295 of 364 extracted entities (81% retention), with 63–90% relationship retention.
  • Reduced LLM processing cost by 48× compared with the baseline approach.
  • Tested by: two-stage validation (does it fit the schema, is it right in context) run on both the guided extraction and an unconstrained baseline, reported per document; every entity carries its source page.

Deep Learning & NLP

IMDb Sentiment Analysis

An end-to-end deep-learning NLP application for classifying sentiment in movie reviews. Uses custom-trained Word2Vec embeddings with a neural network classifier, model comparison, evaluation, and live deployment.

  • Achieved 83.8% test accuracy and 0.84 F1 on 50K IMDb reviews.
  • Trained Word2Vec embeddings from scratch and compared Global Average Pooling, Flatten-MLP, and LSTM architectures.
  • Used leakage-free training, validation, and test splits for model selection and final evaluation.
  • Containerised the application with Docker and deployed it as an interactive live demo.
  • Tested by: three architectures on identical splits, one change at a time; full precision, recall and F1, not one headline number; unit tests on embeddings and preprocessing.
